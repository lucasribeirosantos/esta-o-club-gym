# Estação Club Gym — protótipo de site

Landing page de apresentação para a Estação Club Gym (Divinópolis-MG). Site estático: HTML/CSS/JS puro, sem build.

## Rodar localmente

Abra `index.html` no navegador, ou sirva a pasta:

```powershell
powershell -ExecutionPolicy Bypass -File servir.ps1
```

## Antes de virar o site oficial

Procure por `PLACEHOLDER` e `TODO` no `index.html`:

- preços dos planos (estão em R$ 0,00)
- depoimentos (exemplos fictícios)
- horários de funcionamento
- fotos em `img/` (ilustrativas, trocar por fotos reais da academia)
- remover a meta `noindex` no `<head>`
